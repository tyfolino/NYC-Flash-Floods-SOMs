Figure 2. Evolution SOM (evSOM) node weight patterns at four key hours preceding flash flood episodes. The 2×2 evSOM was trained on 24-hour windows of standardized Z500 and 850-hPa θe anomalies centered on each of the 121 flash flood episodes (1996–2025). Each row corresponds to one evSOM node (A1, A2, B1, B2); each column shows a different hour offset (T−18h, T−12h, T−6h, T=0, where T=0 is the flash flood event time). Contours show standardized Z500 anomaly (interval: 0.2σ; negative dashed); shading shows standardized 850-hPa θe anomaly. Node labels include the number of episodes assigned (n).
